# Budget prévisionnel — Matchs Amicaux

## Coûts fixes annuels (hébergement technique)

| Poste | Option gratuite actuelle | Recommandée pour 1000 clubs | Coût annuel estimé |
|-------|--------------------------|-----------------------------|-------------------|
| **Vercel** | Hobby (0 €) | **Pro** — 20 €/mois | **240 €/an** |
| **Supabase** | Gratuit | Gratuit (pooler session 15 connexions) | **0 €/an** |
| **Nom de domaine** | .vercel.app gratuit | .fr ou .com chez OVH/Gandi | **10–20 €/an** |
| **Emails transactionnels** | Brevo gratuit (300/jour) | Brevo gratuit ou Starter | **0–300 €/an** |
| **Web analytics** | Vercel inclus | Vercel inclus | **0 €/an** |

**Total technique annuel : ~250–550 €**

## Évolutions possibles

| Poste | Quand ? | Coût estimé |
|-------|---------|-------------|
| Supabase Pro (plus de connexions / stockage) | Si >100 visiteurs simultanés ou beaucoup d’uploads | **~115 €/an** |
| Brevo Starter (plus d’emails) | Si >300 emails/jour | **~220 €/an** |
| Vercel Pro avec sièges supplémentaires | Si équipe >1 personne | **+20 €/mois/personne** |
| Add-on IPv4 Supabase | Si on veut connexion directe | **Prix variable** |

## Scénarios

### Scénario 1 : Gratuit / démarrage
- Vercel Hobby : 0 €
- Supabase gratuit : 0 €
- Brevo gratuit : 0 €
- Domaine .vercel.app : 0 €
- **Total : 0 €/an**
- **Limite : usage non-commercial, 4 CPU-heures/mois, 15 connexions DB**

### Scénario 2 : Stable pour 1000 clubs (recommandé)
- Vercel Pro : 240 €
- Supabase gratuit : 0 €
- Brevo gratuit : 0 €
- Nom de domaine .fr : 15 €
- **Total : ~255 €/an (≈ 21 €/mois)**

### Scénario 3 : Croissance / fort trafic
- Vercel Pro : 240 €
- Supabase Pro : 115 €
- Brevo Starter : 220 €
- Nom de domaine : 15 €
- **Total : ~590 €/an (≈ 49 €/mois)**

## Recommandation

Pour toi aujourd’hui : **passer au Scénario 2** dès que le site a du trafic réel ou une utilisation commerciale. Ça coûte **~21 €/mois**, ce qui est couvert par **1 ou 2 sponsors locaux à 300 €**.

## À inclure dans un dossier de sponsoring

Texte prêt à l’emploi :

> Le site Matchs Amicaux est une plateforme numérique gratuite qui met en relation les clubs amateurs de football pour organiser des matchs amicaux. Les coûts techniques annuels (hébergement, base de données, emails, nom de domaine) sont estimés à **250 €/an** en phase de croissance. Nous recherchons 2 à 3 partenaires locaux à **300 €/an** pour assurer la pérennité technique du service. En contrepartie, votre logo et votre nom seront visibles sur la page d’accueil et dans les emails envoyés aux clubs.

## Prochaines étapes

1. Passer à Vercel Pro quand nécessaire.
2. Acheter un nom de domaine simple (ex: matchs-amicaux.fr).
3. Contacter 3 sponsors potentiels (magasins de sport, traiteurs, assurances).
4. Préparer un dossier ANS-PSF ou FAFA si éligible.
